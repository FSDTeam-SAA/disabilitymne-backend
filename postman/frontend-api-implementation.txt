=====================================================================
A) ADMIN EXERCISE GLOBAL DEFAULTS (FOR EVERYONE)
=====================================================================

API Name (Postman): Exercise Management - Create Exercise (Global Defaults)
Method: POST
URL: {{baseUrl}}/api/v1/exercises/admin
Role: Admin
Implementation:
- Creates exercise with global training defaults.
- You must choose one mode only:
  a) set_reps mode: executionMode=set_reps with sets + reps (+ optional weightKg)
  b) countdown mode: executionMode=countdown with sets + durationSeconds (+ optional reps, optional weightKg)
- Or send advanced field: defaultSets[] (all sets must follow one mode).
- If weight is omitted, backend uses weightKg = 1 by default.
- Supports multipart/form-data (images/videos).

Body (form-data typical):
- exerciseName (required)
- userType: all_user | premium_user
- assignedUser (required if userType=premium_user)
- executionMode: set_reps | countdown
- sets, reps, durationSeconds, weightKg (simple mode)
- OR defaultSets (JSON string array), each item:
  { setNumber, reps?, durationSeconds?, weightKg? }
- description, keyBenefits, muscleGroups
- exerciseImages (file), targetMuscleImages (file), demoVideo/demoVideos (file)
- status, isVisibleInLibrary

Response keys:
- data.defaultSets
- data.executionMode
- data.countdown (boolean for UI mode switch)
- data.durationSeconds (number when countdown=true)
- data.sets, data.reps, data.weightKg


API Name (Postman): Exercise Management - Update Exercise (Global Defaults)
Method: PATCH
URL: {{baseUrl}}/api/v1/exercises/admin/{{exerciseId}}
Role: Admin
Implementation:
- Updates admin defaults for all users.
- Users with personal override still see their own custom settings.
- Same payload rules as create.


API Name (Postman): Exercise Management - Exercise Detail
Method: GET
URL: {{baseUrl}}/api/v1/exercises/admin/{{exerciseId}}
Role: Admin
Implementation:
- Use this to prefill edit screen.
- Returns defaultSets and quick summary values.


=====================================================================
B) USER PERSONAL EXERCISE OVERRIDE (PER USER ONLY)
=====================================================================

API Name (Postman): Exercise Settings Screen - Get Effective Settings
Method: GET
URL: {{baseUrl}}/api/v1/users/me/exercises/{{exerciseId}}/settings
Role: Authenticated User
Implementation:
- Returns resolved config for this user and exercise.
- Key response fields:
  - executionMode
  - countdown (boolean)
  - durationSeconds (countdown value)
  - defaultSets (admin values)
  - customSets (user override)
  - effectiveSets (custom if exists, else default)
  - hasCustomSettings (boolean)
  - sets/reps/weightKg (from effective first set)


API Name (Postman): Exercise Settings Screen - Save My Custom Settings (User Override)
Method: PUT
URL: {{baseUrl}}/api/v1/users/me/exercises/{{exerciseId}}/settings
Role: Authenticated User
Implementation:
- Saves override only for current user.
- Two payload options:
  1) customSets[] (advanced)
  2) setCount + reps OR durationSeconds + optional weightKg (simple)
- Custom sets must follow the same executionMode as the admin exercise:
  - set_reps: reps required, durationSeconds not allowed
  - countdown: durationSeconds required, reps optional
- If weightKg omitted, backend defaults to 1.

Body example (advanced):
{
  "customSets": [
    { "setNumber": 1, "reps": 12, "weightKg": 1 },
    { "setNumber": 2, "reps": 10, "weightKg": 1.5 }
  ]
}

Body example (simple):
{
  "setCount": 3,
  "reps": 12,
  "weightKg": 1
}


API Name (Postman): Exercise Settings Screen - Reset My Custom Settings (Use Admin Defaults)
Method: DELETE
URL: {{baseUrl}}/api/v1/users/me/exercises/{{exerciseId}}/settings
Role: Authenticated User
Implementation:
- Deletes user override.
- Next read uses admin defaultSets.

Frontend Flow (Recommended)
=====================================================================
1) Load program detail (or programs list), check exercise.countdown (boolean), then render exercise.effectiveSets.
2) If user edits sets/reps/time/weight for an exercise, call PUT settings endpoint.
3) Reload settings/program to reflect hasCustomSettings + effectiveSets.
4) On completion screen, submit workout experience.
5) For help/support screen, submit ticket and show ticket list/status timeline.
